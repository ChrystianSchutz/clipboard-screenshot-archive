# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and do not harass anyone.

## Reporting

If someone's behaviour breaks the Code of Conduct, contact the maintainer through GitHub: [@ChrystianSchutz](https://github.com/ChrystianSchutz). For anything you do not want to say in public, use [GitHub's private vulnerability reporting](https://github.com/ChrystianSchutz/clipboard-screenshot-archive/security/advisories/new) on this repository and mark the report as a conduct issue, or use GitHub's [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature.

All reports are reviewed and kept confidential. The maintainer enforces the Code of Conduct as described in the Contributor Covenant's enforcement guidelines.
