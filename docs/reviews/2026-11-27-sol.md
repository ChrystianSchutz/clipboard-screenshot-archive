# Clipboard & Screenshot Archive — first review

> Translated from Polish; the findings, verdict and file:line references are unchanged. `src/main/app/schowek-master-app.ts` was later renamed to `src/main/app/clipboard-archive-app.ts`. Line numbers refer to the reviewed snapshot (see `REVIEWS.md`).

## Findings

Static review. As the brief required, I did not run the app, the tests or a build.

### Critical

1. **A private copy can end up in SQLite.** `src/main/clipboard/capture-service.ts:44`, `src/main/clipboard/capture-service.ts:71`. The notification records the owner and the privacy markers, but the text is read later, when the queue reaches that entry. If an ordinary copy is waiting in the queue and the user copies a password in the meantime, the read can pick up the password and store it with the ordinary copy's metadata. Bind the text and the metadata to the same clipboard version. On Windows, check the sequence number around the read and reject inconsistent results. In the regression test, use one mutable clipboard. The current test hands every read a pre-assigned text (`src/main/clipboard/capture-service.test.ts:285`).

### Important

2. **IPC trusts any local document in the app window.** `src/main/app/schowek-master-app.ts:61`, `src/main/app/schowek-master-app.ts:207`, `src/main/app/security.ts:27`. Production accepts any `file://`, development mode compares a string prefix, and IPC validation does not require the main frame. If the renderer navigates to another local HTML file, that document in the same `WebContents` gets the preload and passes the sender check, gaining access to the history and to delete operations. Limit trust to the exact app document in the main frame and split channels by window role. Apply the same policy to navigation and redirects. Test the real sender policy, because `src/main/ipc/register.test.ts:51` replaces it with a stub. [Electron security documentation](https://www.electronjs.org/docs/latest/tutorial/security).

3. **Settings promise private-copy filtering where it does not work.** `src/main/app/schowek-master-app.ts:269`, `src/main/clipboard/privacy.ts:8`, `src/renderer/src/features/settings/SettingsView.tsx:85`. On macOS, on Linux and in the Windows fallback mode, `nullSourceProbe` does not provide the data needed to exclude apps or recognize private copies. On Windows, even the working adapter ignores `CanIncludeInClipboardHistory=0`. As a result, a user can copy a secret from an excluded app in fallback mode and find it in the history. Read the value of the Windows marker, make the availability of each protection depend on what the active adapter can do, and reflect it in the settings. [Windows clipboard privacy formats](https://learn.microsoft.com/en-us/windows/win32/dataxchg/clipboard-formats#cloud-clipboard-and-clipboard-history-formats).

4. **A regex can hang the main process.** `src/shared/user-regex.ts:15`, `src/main/storage/database.ts:36`. The heuristic lets expensive patterns through, including alternations with overlapping matches. It is enough for the user to type such a pattern and for the search to hit a long clip with no match. The synchronous `RegExp.test()` then blocks IPC, global shortcuts and clipboard capture. Use an engine with guaranteed linear complexity, or move the search to a worker that can be terminated when it exceeds its budget. Use the same safe semantics when highlighting results.

5. **A failed listener registration on Windows stops the history.** `src/main/clipboard/watchers.ts:38`, `src/main/app/schowek-master-app.ts:214`. When `AddClipboardFormatListener` returns an error, the app logs it and keeps running with its tray icon, but stops detecting copies. Start the fallback mechanism after a failed `start()` and show the real capture state and the availability of privacy protection.

6. **The JSON comparison can treat different data as identical.** `src/shared/json-diff.ts:41`, `src/shared/json-diff.ts:79`, `src/shared/json-diff.ts:179`. Two consecutive 64-bit identifiers, `9007199254740992` and `9007199254740993`, collapse into the same `number` after parsing. When array order is ignored, canonicalization also loses an own `__proto__` key, so the presence of that field may not affect the result. Keep number precision during parsing and build canonical objects without the inherited setter. Add regressions for both cases, including the side-by-side view.

7. **The order of clipboard reads can swap A and B.** `src/main/app/schowek-master-app.ts:97`, `src/main/clipboard/capture-service.ts:59`. The comparison state is updated in the order the reads finish. If the read after the second press finishes first, the user can get B as A. Assign the order at the moment of the key press, start the read immediately and apply the results in the order of the requests. Discard results started before a reset or before a comparison opened from the history.

8. **The history page size limits the number of records, not the amount of data.** `src/main/storage/clip-repository.ts:186`, `src/renderer/src/features/history/useHistory.ts:98`. A refresh after the next copy can load from SQLite and send over IPC up to 500 full clips of a million characters each. With a history made of large logs, this can cause a hang or run out of memory. Return metadata and a bounded preview, and load the full content on demand by ID. Add a response size budget.

9. **CI does not check that the packaged app starts with the real Windows clipboard.** `.github/workflows/ci.yml:52`, `.github/workflows/ci.yml:76`, `tests/e2e/fixtures.ts:45`. E2E uses an in-memory clipboard, and the packaging job ends once the package is created. A missing Koffi binary or a failed adapter initialization can pass both jobs. Add a launch test of the packaged EXE on a separate profile that checks an ordinary copy, a private copy and that the preload works.

### Minor

10. **The FFI declaration of Win32 `BOOL` is wrong.** `src/main/clipboard/win32/user32.ts:79`. Koffi reads `bool` as a one-byte type, while Win32 returns a 32-bit `BOOL`. If a function returns a true value whose lowest byte is zero, the code can treat success as failure. Define `BOOL` as `int32_t` in the signatures and convert it to a boolean at the adapter boundary. [Win32 types](https://learn.microsoft.com/en-us/windows/win32/learnwin32/windows-coding-conventions), [Koffi types](https://koffi.dev/primitives).

11. **Escape in the comparison window hides the palette.** `src/renderer/src/features/compare/CompareApp.tsx:35`, `src/main/app/schowek-master-app.ts:195`. The user presses Escape in the Compare window and the window stays visible, because `window:hide` always calls `hidePalette()`. Hide the sender's window based on its verified role and add an E2E regression.

12. **"Launch at login" saves the preference before the result of the system call.** `src/main/app/schowek-master-app.ts:119`, `src/main/app/schowek-master-app.ts:273`, `src/renderer/src/features/settings/SettingsView.tsx:133`. On Linux, the option calls an API that exists only on macOS and Windows, after the value has already been written to SQLite. The user can see the setting enabled after a restart even though autostart was never set. Hide the option on unsupported platforms and save the state after the system call confirms it. [Electron documentation](https://www.electronjs.org/docs/latest/api/app#appsetloginitemsettingssettings-macos-windows).

## What is good

- The sandbox, `contextIsolation`, disabled `nodeIntegration` and a preload that exposes specific operations form a good isolation base. Zod validation covers every `invoke` channel.
- The repository uses SQL parameters, writes the clip update and the copy event in one transaction, and has a deterministic cursor `(last_copied_at, id)`.
- The clipboard and adapter ports make it possible to test the logic without starting Electron. The migration tests check the rollback of a failed change and the refusal to open a newer schema.
- The Win32 code limits the size of native reads and releases locks and handles in `finally`. The packaging configuration unpacks the native Koffi packages separately.

VERDICT: Not OK: private copies can end up in SQLite, IPC trusts any local document, and regex search can block the main process.
